# Product

Atlas is a field guide to abilities an assistant can gain through MCP servers.

People should arrive with a wish ("query my database", "drive a browser", "something nobody has built") and leave with a plate, an install snippet, and a reason to trust or refuse the server. If nothing fits, the wish becomes a public request on that copy of the Atlas.

## Loop

Discover, understand, inspect, install, use, request what is missing.

The printed edition is a curated set of public servers. The official MCP registry can be consulted live during search, and those hits stay visually separate because the registry matches names, not abilities, and this edition does not inspect their tools.

## What a plate claims

A plate claims a repository, a summary, an install path only when the package or remote URL was checked, and GitHub facts observed on 2026-10-02. It does not claim a safety score, an install count, or that a star count belongs to one server inside a monorepo.

## What it refuses

No credential theft, no unofficial account generators, no paywall or captcha bypass, no execution of submitted code. A Hinge wish is a ledger entry asking for a permitted interface. It is not a scraper.

## This edition's ledger

Requests, votes, comments, and submissions live in a local SQLite file. Votes start at zero. Edition entries are labeled as opened with the edition. Approved submissions appear to an editor; they do not silently become plates.
