# Design

Atlas is an editorial index of useful and unlikely capabilities. The interface pairs the clarity of a modern studio site with the charm of a field guide: oversized type, warm paper, vivid vermilion, generous margins, and precise little labels.

## Type

- Helvetica Neue, with Host Grotesk as fallback, for interface and large headlines
- Gilda Display for italic display accents and longer editorial moments
- IBM Plex Mono for counts, plate numbers, filters, and installation code

## Color

Paper `#F0EEE7`, ink `#11110F`, muted text `#77746B`, rules `#D4D0C5`, vermilion `#AB3929`. Dark sections use ink and cream. Color marks navigation or a change in editorial pace rather than a fake trust score.

## Images

Three original images in `public/editorial` give the landing page a tactile world of physical instruments, rooms, and a red connecting cable. The existing engravings remain as category and article art. Publisher favicons are cached locally for recognizable server identities; unknown and community tools receive a typographic initial.

## Interaction

Search remains the main entrance. Category cards, filters, the strange shelf, and Field notes provide other ways in. Motion is restrained to page arrival, a small live-edition pulse, and hover reveals. Reduced-motion settings disable it. `/` and Ctrl/Cmd K open search.

The catalog distinguishes publisher facts from an endorsement. Install and trust details stay visible on each server plate.
